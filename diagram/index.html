ContractAI — System Flowcharts

Interactive visual workflows explaining how ContractAI works in the backend, how user inputs travel to the LLM, and how verified responses are streamed.

1. System Overview & Backend Flowchart

End-to-end flow from user typing a question to retrieval, Gemini analysis, zero-trust verification, and live streaming.

flowchart TD
    A["👤 User Types Question
e.g., 'What is the liability cap?'"] --> B["💻 Frontend UI (ChatPanel)"]
    B --> C["⚙️ Backend API Route
(/api/chats/[id]/messages)"]
    C --> D["🔍 Keyword Search Engine
Finds relevant clauses in the contract"]
    D --> E["📦 Prompt Builder
Combines: System Rules + Contract Text + Question"]
    E --> F["🧠 Google Gemini LLM
Reads clauses & drafts candidate answer"]
    F --> G["🛡️ Citation Verifier
Checks if quotes exist in the real document"]
    G -->|Quote Exists| H["✅ Verified Citation
Finds exact page number & coordinates"]
    G -->|Quote Not Found| I["❌ Rejected Quote
Discards hallucinated reference"]
    H --> J["⚡ Live Stream (SSE)
Streams text to browser in real-time"]
    J --> K["📱 Chat UI Displays Answer
Clickable citation badges"]
    K -->|User clicks badge| L["🟡 PDF Viewer Highlights Clause
Jumps to page & draws glowing yellow box"]

2. Document Ingestion Flowchart

How contracts (PDF and Word DOCX) are verified, extracted, chunked, and indexed.

flowchart TD
    A["👤 User Drops Contract File
(PDF or Word DOCX)"] --> B["📤 Upload Endpoint
(POST /api/documents/upload)"]
    B --> C{"🛡️ Security Checks"}
    C -->|Size > 50MB or Bad File| D["❌ Reject Upload"]
    C -->|Valid PDF or DOCX| E["💾 Save Raw File to Disk"]
    E --> F["📝 Create Database Record
Status: 'Processing'"]
    F --> G{"File Type?"}
    G -->|PDF| H["📄 PDF Text Extractor
Extracts text + records word (x, y) coordinates"]
    G -->|DOCX| I["📑 Word Extractor
Unzips document.xml & extracts paragraphs"]
    H & I --> J["✂️ Document Chunker
Splits into 1,000-character blocks with overlap"]
    J --> K["🔍 Inverted Keyword Indexer
Builds fast search index"]
    K --> L["✅ Mark Document 'Ready'"]
    L --> M["🖥️ Opens in Document Workspace"]

3. User Input to LLM & Response Flowchart

How user prompts are protected against prompt injection and sent to Google Gemini.

flowchart TD
    A["👤 User Types Question in Chat"] --> B["🖱️ Clicks 'Send'"]
    B --> C["🌐 POST /api/chats/[id]/messages"]
    C --> D["💾 Save Question in Database"]
    C --> E["🔍 Search Contract Index
Finds top matching clauses"]
    E --> F["🛡️ Assemble Protected Prompt
Puts contract text inside <evidence> tags"]
    F --> G["📋 Add LLM Instructions
(Normal sentence case, selective bolding, quotes only)"]
    G --> H{"Gemini API Key?"}
    H -->|Yes| I["🧠 Google Gemini LLM
Generates legal reasoning + candidate quotes"]
    H -->|No / Offline| J["⚙️ Deterministic Legal Engine
Synthesizes structured answer"]
    I & J --> K["⚡ Stream Words to Browser (SSE)"]
    K --> L["🛡️ Verify Quotes in Background"]
    L --> M["✅ Render Final Answer in Chat"]

4. Zero-Trust Citation Verification Flowchart

How quotes are deterministically checked to guarantee zero hallucinated citations.

flowchart TD
    A["🧠 LLM Returns Candidate Quote
e.g., 'thirty-day (30-day) written notice'"] --> B["🛡️ Zero-Trust Verification Engine"]
    B --> C{"Does quote exist in real document?"}
    C -->|No Match Anywhere| D["❌ REJECT QUOTE
Blocks AI hallucination"]
    C -->|Exact / Normalized Match| E["📍 Find Exact Character Position
Characters 3,892 to 3,925"]
    E --> F{"Appears multiple times?"}
    F -->|Repeated Text| G["🎯 Disambiguate Occurrence
Picks quote from section AI was reading"]
    F -->|Unique Text| H["✅ Confirmed Offset"]
    G --> H
    H --> I["📄 True Page Number Lookup (e.g., Page 4)"]
    I --> J["📐 Calculate PDF Canvas Coordinates (x, y, w, h)"]
    J --> K["💳 Display 'Verified Clause • Page 4' Badge"]
    K -->|User clicks badge| L["🚀 Viewer Jumps to Page 4 & Pulses Glowing Yellow Box"]

5. Advanced Features: Agentic Deep Research & Redlining

Multi-step autonomous ReAct agent loop and native WordprocessingML tracked changes.

flowchart TD
    A["👤 User Enters Redline Request
e.g., 'Increase termination notice from 30 to 60 days'"] --> B["⚙️ Propose Endpoint (POST /api/redline)"]
    B --> C["🔍 AI Locates Targeted Clause
Finds exact text: 'thirty-day (30-day)'"]
    C --> D["✏️ Proposes Exact Replacement
Replacement text: 'sixty-day (60-day)'"]
    D --> E["🛡️ Verifies Target Exists in Document
Ensures surrounding text remains 100% untouched"]
    E --> F["🖥️ Displays Visual Diff Preview in Browser
~~thirty-day (30-day)~~ in RED
sixty-day (60-day) in GREEN"]
    F --> G["📥 User Clicks 'Download Redlined DOCX'"]
    G --> H["⚙️ Apply Endpoint (POST /api/redline/apply)"]
    H --> I["📂 Unzips Word Document (JSZip)
Opens word/document.xml"]
    I --> J["🏷️ Injects Native Tracked Changes Markup:
• <w:del> for deleted words
• <w:ins> for inserted words
• Adds author='ContractAI' and date"]
    J --> K["📦 Re-packages Clean .docx File"]
    K --> L["💾 Download 'redlined-contract.docx'"]
    L --> M["📑 Open in Microsoft Word or LibreOffice
Native 'Accept' and 'Reject' buttons work instantly!"]
